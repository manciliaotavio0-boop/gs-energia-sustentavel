Descrição:

Este projeto foi desenvolvido para simular o monitoramento de uma missão espacial experimental.

O sistema recebe dados operacionais da missão, monitora condições críticas e gera alertas automáticos para auxiliar na tomada de decisões.

Funcionalidades:

Monitoramento de temperatura

Monitoramento de energia

Monitoramento da comunicação

Verificação dos módulos da nave

Geração automática de alertas

Tomada de decisão automatizada

Tecnologias Utilizadas:

- Python (colab)

Objetivo :

Desenvolver uma solução computacional capaz de monitorar sistemas energéticos de uma missão espacial experimental, aplicando conceitos de energia, sustentabilidade, programação e automação.
